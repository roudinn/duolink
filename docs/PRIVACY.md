# Конфиденциальность DuoLink

В DuoLink можно играть по коду без регистрации. Ник требуется для списка друзей и появляется в поиске после сохранения.

## Что видят участники

Видео, звук и ввод передаются между компьютерами по зашифрованному QUIC-соединению. Сервер DuoLink помогает обменяться адресами и доставить приглашение. Если прямое подключение не работает, резервный ретранслятор пересылает зашифрованные пакеты. Получая доступ к сессии, гость видит транслируемый экран хоста и получает его игровой звук. При прямом подключении участникам доступны сетевые адреса друг друга.

В коде `DL2-` содержатся адреса хоста и данные для подключения. Отправляйте код тому, кого хотите позвать. Если поделились им публично, завершите сессию и создайте новую.

## Что обрабатывают серверы

| Данные | Назначение и срок |
| --- | --- |
| Запись каталога | Связывает хеш ника с тегом и открытый ключ профиля. Запись хранится до семи дней от последнего обновления. |
| Сообщения друзей | Запросы, ответы и приглашения передаются в зашифрованных сообщениях. Записи хранятся до двенадцати часов. Сервер видит тему, время записи и зашифрованный конверт. |
| Подключение | Зашифрованные адреса гостя хранятся до сорока секунд. Сведения о типе подключения хоста хранятся до двенадцати часов. |
| Ретрансляция | Во время резервного подключения сервер видит сетевые адреса соединений, производный ключ комнаты, время и объём трафика. Видео, звук и ввод зашифрованы между участниками. Ретранслятор хранит маршруты и очереди пакетов в памяти. |
| STUN | Сервер видит IP и порт запроса, чтобы вернуть их клиенту. Для уточнения типа NAT DuoLink может также обратиться к публичным STUN-серверам Google и Cloudflare. |
| Загрузки | Для обновлений и компонентов DuoLink обращается к GitHub, зеркалу DuoLink или официальным источникам компонентов. Эти сервисы получают обычные сетевые данные запроса. |

На рабочем сервере отключено журналирование HTTP-запросов и входящих TLS-соединений для маршрута DuoLink. Старые записи соединений в общем журнале автоматически уходят при ежедневной ротации. Настроено хранение 14 архивов. Доступ к SQLite и резервным копиям ограничен на VPS. Сроки в таблице относятся к рабочей базе.

## Что хранится на ПК

- Профиль, список друзей, настройки и журналы хранятся в `%LOCALAPPDATA%\DuoLink`. С v1.14.8 Windows защищает ключ профиля через DPAPI. При обновлении DuoLink переносит старый ключ без смены ника и тега. Для чтения защищённого профиля используется та же учётная запись Windows.
- Временные файлы Sunshine с ключом сессии доступны владельцу и SYSTEM.
- С версии 1.14.9 статус Discord включён по умолчанию. Его можно отключить в настройках. При включении приложение Discord получает состояние DuoLink и число игроков в лобби. Коды сессий и ники в статус не входят.

Для баг-репорта прикладывайте только нужный журнал из папки `logs`. Удалите из него личные данные, IP-адреса и коды сессий. Файлы профиля, конфигурации и ключей оставьте у себя.
