Play local co-op online

Run the game on your Windows PC. Your friend joins by code and plays with a separate gamepad.

Download for Windows GitHub repository

Start a session

  1. Download and run DuoLink on both PCs.
  2. The host launches the game and sends the session code.
  3. The guest enters the code and the host approves the connection.

Which games work

Games with local multiplayer and support for multiple gamepads, including fighting games, split-screen games, and emulators. Only the host needs the game.

Connect without a VPN

DuoLink sends video, audio, and controller input directly between players over QUIC. If the network blocks a direct connection, try switching hosts. There is no built-in relay.

Video and latency

DuoLink supports hardware AV1 or HEVC encoding and decoding on compatible devices. Set the bitrate manually or let it adapt automatically. DuoLink has no built-in FPS or resolution cap. Latency depends on the route and devices.
